# UAV-DETECT-02

本版仅保留无人机检测、PCIe/RGA/DRM视频、九宫格选路、FPGA控制、PTZ手动控制、风扇与状态监测。

输入是PCIe选路ROI，原帧指针只在提交期间使用，按限帧复制到latest-only单槽；推理线程将RGB565转RGB888并等比例letterbox到640×640，RKNN输出单类decoded [1,5,8400]，CPU完成阈值/NMS，回映射为选路640×360坐标供HDMI OSD与Qt显示。总览输入取完整1920×1080，单通道取九宫格中640×360 tile；无法恢复FPGA拼接前已丢失的分辨率。

默认推理关闭，用户启动HDMI后在无人机页启用。目标FPS默认5，可设1～30，但实际吞吐须上板测量。预处理本版使用CPU以固定RGB顺序及letterbox映射，可能增加CPU负载；不承诺维持原模型帧率。模型FP16未量化，无需伪造校准集；后续使用真实无人机小目标图像校准INT8并比较召回。

本版PTZ预览不作为检测源、不自动跟踪、不包含无人机型号分类，只进行drone单类目标检测。模型未上板验证，候选场景精度需实测。
