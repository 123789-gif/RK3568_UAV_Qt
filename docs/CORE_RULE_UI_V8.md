# v8 核心规则任务与页面布局验收

## 修改目标

- FPGA配置页的两个功能区按3:2使用可用高度，加大模式与以太网输出按钮。
- 车牌页模式区增加底部安全边距，四个60 px按钮不得裁掉底边或圆角。
- 行人页删除强制红/绿灯试验入口，正式运行只采用自动灯态识别。
- 行人违法和车辆逆行改为独立的大型核心按钮；模型未启动时，点击核心按钮会一次性提交“启动对应模型＋开启CPU规则”。

## 明确的状态语义

| 操作 | 模型状态 | CPU规则状态 |
| --- | --- | --- |
| 模型未启动时点击核心判定 | 自动启动 | 开启 |
| 模型运行时点击核心判定 | 保持运行 | 开启 |
| 关闭核心判定 | 保持运行，便于观察原始检测框 | 关闭 |
| 关闭模型 | 关闭 | 同时关闭 |

核心判定仅在已启动PCIe视频且当前输入为总览1080P时可用。若尚未配置区域，按钮允许点击，但不会启动任务，页面会明确提示缺少的区域配置。

## 行人页兼容处理

旧版`pedestrian_violation.ini`可能保存了强制红灯或强制绿灯。v8加载后会在内存中立即转为自动灯态，下次保存配置或启动违法判定时持久化，避免隐藏UI状态继续影响演示。

## 上板验收顺序

1. 启动后确认窗口标题包含`BUILD-CHECK-08`。
2. 进入FPGA配置页，确认按钮高度增大且页面底部无大块空白。
3. 进入车牌识别页，确认四个模式按钮底边和两个底部圆角完整。
4. 启动PCIe视频，前端选择一路总览1080P。
5. 在行人模型关闭时直接点击“开启行人违法判定”，确认模型和规则同时运行；关闭规则后原始行人框仍继续输出。
6. 在车辆模型关闭时直接点击“开启车辆逆行判定”，确认模型和规则同时运行；关闭规则后原始车辆框仍继续输出。
7. 在两个页面各连续切换模型/规则10次，确认Qt不退出、HDMI不返回桌面。
