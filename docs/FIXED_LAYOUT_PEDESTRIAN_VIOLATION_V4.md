# 固定车牌布局与总览行人违法 v4 验收

## 输入约定

前端输出一路完整的 1920×1080 画面，Qt 侧统一选择“总览1080P”。它不是九宫格中的 1/9 小画面。行人模型、行人违法规则、车辆模型和逆行规则均以该总览画面为坐标基准。

## 页面行为

- 顶部标题使用 28 px 字体，八个导航按钮使用 20 px 字体并继续等分高度。
- 车牌页不使用整页滚动容器。模式区固定 170 px，运行状态区固定 210 px，其余区域在页面首次布局时分配；按钮选中、模型切换和结果文本刷新均不得改变区域高度。
- 行人页使用一个行人 RKNN 任务。“开启行人模型”只输出全部原始行人框；“违法判定”只开关 CPU 规则，不重新加载模型。

## 行人数据流

```text
总览1080P → 统一NPU输入 → ped_det.rknn → 全部原始行人框
                                      └→ 站姿规则候选副本
                                          → 信号灯ROI
                                          → 斑马线脚点
                                          → 轨迹和持续时间
                                          → 违法事件
```

`pedestrians` 始终保存全部置信度/NMS结果；`violationPedestrians` 仅保存 CPU 规则候选。规则产生的轨迹状态按原始索引回填，因此开关规则不能改变界面中的原始检测数量。

## 上板检查

1. 视频显示页选择“总览1080P”，确认前端单路画面填满 HDMI。
2. 进入车牌页，循环切换四种模式和逐帧/稳定策略，检查各区域高度、应用按钮和页面底部均不移动，不出现整页滚动条。
3. 进入行人页，不配置区域直接开启模型，确认能显示原始行人框。
4. 配置交通灯矩形与斑马线四点并保存，开启违法判定；确认 PID 不变、日志不出现行人模型重新加载。
5. 记录开启规则前后的原始行人数量，同一输入帧附近不应因站姿筛选产生系统性减少。
6. 使用强制红灯验证轨迹累计与事件，再切换强制绿灯，当前违法状态必须清零。
7. 关闭违法判定，原始行人模型继续运行；关闭行人模型后两层同时停止。
8. 行人模型运行时切换到 CH 路由，程序应主动停止该模型，防止总览 ROI 错配。
9. 逆行页使用总览时，让车辆跨过画面横向或纵向 1/3 位置，轨迹 ID 和方向累计必须连续；这些位置不再被当作九宫格边界。
